# Behavioral Modelling

Projects implemented using behavioral modeling — described using `always` blocks
with procedural constructs (`if-else`, `case`), representing the circuit's
behavior at a higher level of abstraction rather than its gate-level structure.

## Projects

- **2x1_Multiplexer** — 2-to-1 multiplexer

Each project folder contains its own README with the specific problem, design
approach, and result, along with the Verilog source, testbench, schematic image,
and waveform image.
